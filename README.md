## 三步找到适合的工具

1. **先描述任务。** 在首页输入工具名称或用途，例如 `JSON`、`图片压缩`、`AI 写作`。明确输入内容、预期输出和使用频率，比只搜“最好用的工具”更容易筛选。
2. **按分类和标签缩小范围。** 阅读用途简介；分类列表提供排序和筛选。查看工具详情或官网入口，确认是否支持你的格式、平台和使用场景。
3. **先试一个小任务，再加入常用。** 用不含敏感信息的样例验证结果。网站的星标收藏保存在当前设备的浏览器中，方便下次访问。

## 三个常见工作流

### 为独立项目选择工具

先从[域名分类](https://tool.dreamthere.cn/cate/domain)查找域名服务，再到 [API 分类](https://tool.dreamthere.cn/cate/api)了解接口服务。比较时记录续费价格、接口限额、可用地区和数据导出方式，避免只按首购价格决定。

### 为网站做内容与 SEO 准备

从[关键词研究分类](https://tool.dreamthere.cn/cate/keywords)寻找研究工具，整理读者问题，再用 [SEO 分类](https://tool.dreamthere.cn/cate/seo)寻找检查和分析工具。先确认搜索意图与目标页面是否匹配，再考虑扩展内容。

### 为内容制作挑选 AI 工具

分别浏览 [AI](https://tool.dreamthere.cn/cate/ai)、[图片](https://tool.dreamthere.cn/cate/img)和[视频](https://tool.dreamthere.cn/cate/video)分类。用同一份样例比较结果、导出规格、水印、费用及商用条款，留下能够完成实际任务的工具。

## 常见问题

### 这些工具都能在本站直接使用吗？

本站是按用途整理的工具导航。你可以在这里发现和比较工具，再通过相应入口访问第三方官网；具体服务由各工具提供。

### 收录的工具都免费吗？

不同产品有各自的免费或付费方案。被收录不代表永久免费，也不代表所有功能无需注册。使用前核对官网当前说明。

### 收藏需要注册吗？会跨设备同步吗？

网站星标收藏无需注册，保存在当前设备的浏览器中。更换设备、浏览器或清理网站数据后不会自动同步；重要工具也可以另存浏览器书签。

### 找不到合适的工具怎么办？

换一个更具体的任务词，或从分类切换到标签继续查找。知道值得补充的产品，可以通过[推荐工具入口](https://tool.dreamthere.cn/site/submit)填写名称、网址、分类和用途，审核后收录。

### 如何报告失效链接或错误介绍？

请通过本仓库的 [Issues](https://github.com/yjkhxy/tool.dreamthere.cn/issues)提供受影响页面、工具名称、问题描述、官网依据及检查日期。提交格式见[贡献说明](CONTRIBUTING.md)。文档修改与网站数据维护分别处理，仓库合并不会自动更新网站。
